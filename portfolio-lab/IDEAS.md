# Идеи после просмотра референса

Согласованные улучшения реализованы: подсветка показателей и разница относительно выбранного портфеля, общий период, именованные наборы сравнения с сохранением данных в браузере.

Следующие идеи пока остаются предложениями:

- **Понятные профили стратегии.** В референсе выбор начинается с цели пользователя. В лаборатории можно добавить готовые профили «Осторожный», «Баланс» и «Рост», которые заполняют параметры, сохраняя видимыми названия критериев и формулы для учебной работы.
- **Подсказки о качестве данных у индикатора.** В референсе рядом с инструментами показаны особенности их истории. У нас можно аналогично показывать источник, единицы, дату обновления и длину ряда, чтобы пользователь понимал причину ограничений расчёта.
- **Отдельный сценарный экран.** Референс отделяет будущие сценарии от исторической проверки. Для лаборатории полезно сравнивать диапазоны результата по нескольким явным допущениям, показывая их рядом с параметрами и не смешивая с фактической историей.
- **План покупок как отдельный режим.** Учёт лотов, комиссий и остатка бюджета полезен для инвестиционных инструментов. Он потребует реальных торгуемых активов, актуальных цен и правил покупки; состав учебной модели с макроиндикатором М2 для этого не подходит целиком.

Начал бы с профилей стратегии и подсказок о данных: они упрощают работу с существующими расчётами и сохраняют учебную методику.

# GitHub Pages и официальная статистика

Сайт опубликован по адресу https://mally2118.github.io/analyseB_Pack/ . Отдельный сервер для загрузки статистики не нужен.

В Settings → Pages выбрано **Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует `portfolio-lab/dist` при обновлении `main`, ручном запуске и ежедневно в 05:23 UTC / 08:23 по Москве. Запуски по расписанию могут задерживаться со стороны GitHub.

При каждом запуске Node.js получает официальные данные ЦБ, Росстата и MOEX, проверяет полноту всех месячных рядов и формирует `dist/data/market-data.json`. Браузер загружает этот файл с самого сайта и выбирает заданные месяцы. Прямые запросы браузера к ЦБ и Росстату блокируются CORS источников; настройки GitHub Pages этого не меняют. API-ключи для этих источников не требуются.

Последняя успешная выгрузка сохраняется в кеше Actions. При недоступности источников используется она, а при отсутствии кеша — проверенная выгрузка из репозитория. Дата успешного обновления сохраняется и видна в форме загрузки; данные не дополняются синтетическими значениями. Неполная или некорректная новая выгрузка не заменяет предыдущую.

Для ручного обновления откройте [Actions → Deploy GitHub Pages](https://github.com/Mally2118/analyseB_Pack/actions/workflows/pages.yml), нажмите **Run workflow**, выберите `main` и запустите. Шаг Refresh official statistics показывает результат загрузки, при сохранении предыдущих данных — предупреждение.

Для подробной проверки соединений включите **diagnostics** при ручном запуске. Журнал покажет доступность официальных адресов, причину сетевой ошибки и издателя публичного сертификата Росстата.

Сертификаты Росстата проверяются с официальной цепочкой Минцифры, полученной с Госуслуг. Подготовка доверенной цепочки проверяет отпечаток корневого сертификата, подпись промежуточного и сроки действия. При смене промежуточного сертификата новый принимается только с подписью того же проверенного корня. `NODE_EXTRA_CA_CERTS` применяется к процессу загрузки статистики в Actions; проверка HTTPS остаётся включённой, системное хранилище и браузер не меняются. Официальные адреса и отпечатки приведены в [certs/README.md](portfolio-lab/certs/README.md).

Локальное обновление: `node portfolio-lab/update-market-data.mjs`. Флаг `--strict` завершает команду ошибкой при недоступности источников, даже если существует резерв. Обычный локальный сервер продолжает поддерживать `/api/market-data`.

Workflow использует права `contents: read`, `pages: write`, `id-token: write`. Запись коммитов и дополнительные секреты не нужны. В публичном репозитории GitHub отключает расписание после 60 дней без активности: его можно снова включить в Actions. Подробнее: [расписания GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

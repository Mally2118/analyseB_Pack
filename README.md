# analyseB_Pack - Портфельная лаборатория

Веб-приложение. 10 индикаторов, четыре критерия оптимизации, поправка на инфляцию, сравнение графиков и импорт Excel.

Приложение и инструкция находятся в [portfolio-lab](portfolio-lab/README.md).

Для запуска в Windows нажмите `portfolio-lab/Запустить.bat` и откройте http://127.0.0.1:4173. Требуется Node.js. Библиотеки уже включены в проект.

Открыть сайт: [Портфельная лаборатория](https://mally2118.github.io/analyseB_Pack/). Во вкладке «Данные» можно загрузить официальную статистику ЦБ, Росстата и Мосбиржи без отдельного сервера: GitHub Actions ежедневно проверяет новые публикации. Настройка и ручное обновление описаны в [инструкции GitHub Pages](DEPLOY_GITHUB_PAGES.md).

Начальный набор данных - синтетический учебный пример; исторические данные доступны через официальную загрузку и Excel.
